🌱 Beginner guide — read this and you are a professional

You will know more than most interview candidates. No prior agent knowledge needed. Work this out in a step-by-step way to be sure we have the right answer.

0 · What is the bug? (30 seconds)

A shop stores prices as whole cents (600 = $6.00). A 10% coupon should give 540. The code subtracts the number 10 itself: 600 − 10 = 590. The test file already knows the right answer. Our job: make the code agree with the test.

python -m pytest shop/test_shop.py -v   # 2 failed, 1 passed
1 · What is a model call? (1 minute)

Your program sends one web request with a list of messages (system = who the model is, user = the task). The server returns text, or a tool call (a request to run something). The model never touches your computer directly — it only asks. See steps/step1_talk_to_model.py.

2 · What is a tool? (1 minute)

A tool is a JSON description: name + what it does + parameters. Our first tool is shell with one string parameter command. Python runs it with bash and sends back exit= plus output as a tool message. See steps/step2_one_tool.py.

3 · What is the agent loop? (the whole secret)

Call the model, run the tools it asks for, repeat until it answers in words. That is 28 lines (steps/step3_agent_loop.py). The model sees full history each round, so errors become evidence for the next try. Production Codex implements the same loop in Rust (turn.rs / run_turn).

4 · Why patches instead of rewriting files?

Rewriting risks dropping lines. apply_patch says: keep these context lines ( ), remove (-), add (+). Our matcher tries exact, then trailing-space-tolerant, then indent-tolerant — like production seek_sequence. Try python benchmarks/bench.py.

5 · How do we stay safe?

Two layers: approvals (dangerous commands like rm -rf / ask first) and sandbox (the OS blocks network and writes outside the workspace). Long output is truncated to 4000 chars. See steps/step5_safety.py.

6 · How does the agent follow project rules?

A short system prompt plus shop/AGENTS.md (integer cents, run tests after edits). Real Codex walks git-root → your folder joining every AGENTS.md (32KB cap). Without it the fix uses floats; with it the fix uses (s*pct+50)//100 and says why. See steps/step6_instructions.py.

7 · What about long tasks and memory?

Every call resends history, so cost grows. When tokens pass a budget, the agent asks the model for a handoff summary, drops old messages, keeps system + instructions + summary. Set the budget too low and it re-reads files forever (14s → 105s). Production compacts near 90–95% of a 272k window. See steps/step7_memory.py.

Let's work this out in a step-by-step way to be sure we have the right answer: bug → failing test → list files → run tests → read code → patch integers → run tests → 3 passed. Each arrow is one loop iteration.
